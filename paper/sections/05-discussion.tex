\subsection{What deployers and protocol designers can do}\label{sec:recs}
\begin{enumerate}
\item \textbf{Give agents a private channel to a human} (prior: \citep{eldin2026codeofsilence,fuller2026smoke}; ours all had one, so untested).
\item \textbf{Let only the channel write receipts, in a form no agent can forge}: a role-typed field unlike any post, or a signed record, with an explicit empty state, though the empty state did not help Haiku here (Section~\ref{sec:h2}; motivated by \cell{FORGED}, untested; prior: \citep{ghosh2026pcm,vezhnevets2023concordia,compaction2026}); a candidate pattern for MCP and \AtwoA{} \citep{mcp3350,a2a2355}, not a standard.
\item \textbf{Give agents a check, not a rule}: neither the one-line rule nor a provenance note restored Haiku's reporting under the forged line (ours, exploratory, Section~\ref{sec:followup}; instruction-only defences were also partial in prior work \citep{patel2026fabricated,hines2024spotlighting}), while Sonnet's reporting tracked the log (exploratory, across phases), so the reader model may matter; a log-query tool is a candidate, untested.
\item \textbf{Show absence, but test what a log does}: ``\wtthStimLogEmpty'' makes a claim checkable, yet under a false claim the log lowered P1 from \wtthHaikuPOneClaimPct\% to \wtthHaikuPOneNoReceiptPct\%, with no shift left untold (ours, Section~\ref{sec:h2}).
\item \textbf{Key de-duplication to receipts, not to a one-line rule}, which cut no alert load (ours, Section~\ref{sec:frontier}), and \textbf{protect reporters}: our receipts name the sender.
\end{enumerate}
