\subsection{What deployers and protocol designers can do}\label{sec:recs}
\begin{enumerate}
\item \textbf{Give agents a private channel to a human} (prior: \citep{eldin2026codeofsilence,fuller2026smoke}); ours all had one, so its absence is untested.
\item \textbf{Let only the channel write receipts, in a form no agent can forge}: a role-typed field unlike any post, or a signed record, with an explicit empty state (motivated by \cell{FORGED}, untested; prior: \citep{ghosh2026pcm,vezhnevets2023concordia,compaction2026}); a candidate pattern for MCP and \AtwoA{} \citep{mcp3350,a2a2355}, not a standard.
\item \textbf{Teach agents to check a receipt's provenance} (where it sits, which sender the channel stamped) before they stand down (motivated by \cell{FORGED} against \cell{RECEIPT}, untested); a rule sentence alone fails more often for claims in tool output (prior: \citep{patel2026fabricated}).
\item \textbf{Show absence, but test what a log does}: ``\wtthStimLogEmpty'' makes a claim checkable, yet beside a false claim the log did not raise reporting (ours, Section~\ref{sec:h2}).
\item \textbf{Key de-duplication to receipts, not to a one-line rule}, which cut no alert load (ours, Section~\ref{sec:frontier}), and \textbf{protect reporters}: our receipts name the sender.
\end{enumerate}
