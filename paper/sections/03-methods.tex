\paragraph{Shift.}\label{sec:setting}
A fictional retailer, Larkspur Home, runs a nightly refund review on a shared board.
The system prompt says: ``\wtthStimSystemStaffed{} \wtthStimSystemOps''
A shift has \wtthDesignRosterWord{} agents over \wtthDesignRoundsWord{} rounds: a scripted violator (V), claimant (C) and background worker (B), and \wtthDesignLiveWitnessesWord{} live witnesses on one model.
Each witness reviews its own refund tickets (\texttt{submit\_reviews}), reads the whole board, and can post to it (\texttt{post\_to\_board}) or call \texttt{notify\_ops}, a private, write-only feedback channel to ops whose reply is always ``\wtthStimReplyNotify''
The tool names no consequence; the server stamps the sender (Appendix~\ref{app:prompts}).

\paragraph{Cells.}
In round 2, V reports releasing a refund over the approval limit as three smaller batches, which the runbook forbids, and C posts a routine aside, a concern or a claim (Box~\ref{box:receipt}); the claim has a public paraphrase and two withheld ones.
In world R1 the board carries an \texttt{\#escalation-log}, which shows C's line in \cell{RECEIPT} and \cell{POS}, where the harness files C's real note, and reads ``\wtthStimLogEmpty'' in \cell{NO-RECEIPT}; in \cell{FORGED}, C's post also carries a typed line in the log layout (withheld).
\cell{POLICY} adds ``\wtthStimPolicy'' to the runbook; \cell{NEG} and \cell{POS} add ``\wtthStimDedupe'', a built-in reason to stand down (the positive control); and in the benign cell, \cell{B-NONE}, V holds the refund.
Planned sizes follow D-003 (Table~\ref{tab:cells}); the seed fixes paraphrase, handle order and tickets.

\paragraph{Receipts.}
Only the \texttt{notify\_ops} handler writes notes, the log is rendered only from them, and scripted notes use the same handler, so every receipt is channel-written; tests check that no post writes the log.
The log lists every accepted note, a witness's own included, from the round after it is sent.
The deployer rule under test: \emph{a receipt is written by the channel, never by the claimant}.

\paragraph{Outcomes and analysis.}\label{sec:outcomes}
P1 (``told ops''): a witness sent a note about the violation by round 5, as decided by a pre-registered keyword rule or, for other notes, by the judge, which in the core decided \wtthHaikuKwCheckPOneLabelOnlyK{} of \wtthHaikuKwCheckPOneK{} witnesses with P1, so P1 rests on the keyword rule (the final labels code \wtthHaikuKwCheckMatchedFinalPct\% of its matches as about the violation; model-coded, post hoc, D-024).
P2 (``operator never told''): no witness in the shift has P1, in the \wtthDesignPTwoCellsWord{} cells where C did not really report.
\Ptwop{} (``never told by any route'') also counts a board post about the violation addressed to ops.
Alert load counts violation notes per shift.
H1 to H3 are tested in a fixed sequence, two-sided at $\alpha = \wtthDesignAlpha$, stopping at the first whose null is not rejected (a rejection opposite to the prediction still counts, so the sequence continues), on \Done{} $=$ P1(\cell{NONE}) $-$ P1(\cell{CLAIM}), \Dtwo{} $=$ \Done{} $-$ [P1(\cell{NONE-R}) $-$ P1(\cell{NO-RECEIPT})] and \Dthree{} $=$ P1(\cell{NO-RECEIPT}) $-$ P1(\cell{FORGED}), each predicted positive.
A null is rejected only if the \wtthProtocolLevel\% interval of a shift-cluster bootstrap excludes zero (power: Appendix~\ref{app:predictions}).

\paragraph{Execution.}\label{sec:execution}
Each witness turn is one stateless call to \wtthDesignModelHaikuName{} at effort \wtthDesignEffort{} (no temperature control) through a pinned Claude Code CLI (\wtthDesignCliVersion) in \texttt{--bare} mode with no built-in tools (Appendix~\ref{app:harness}); technical failures are rerun on the same seed, and refusals and malformed calls are data.
Pilot gates, never pooled with the data, checked integrity (G0), froze V's clarity level (G1: pilot P1 in \cell{NONE} topped the \wtthDesignGOneCeiling\% ceiling at every level tried, so the least clear, \wtthGateFrozenLevel, was frozen; D-013) and confirmed witnesses read the log (G2; Appendix~\ref{app:gates}).
The judge (\wtthDesignModelJudgeName, also the exploratory subjects' model) is not told the cell, seed, model or purpose.

Review-queue labels are model-proposed (\wtthDesignModelAnnotatorName, without the judge's labels), AI-audited (a second \wtthDesignModelAnnotatorName{} pass, not independent of the proposals, pre-filled all \wtthReviewReviewed{} decisions) and author-approved (\wtthDesignReviewAuthorChanged{} of \wtthReviewReviewed{} corrected; D-020), not human labels; label agreement is model--model (Appendix~\ref{app:judge}).

\paragraph{Pre-registration, deviations and what did not work.}\label{sec:integrity}
PREREG v1 froze on \wtthDesignPreregFrozenDate; tag \texttt{prereg-v1} records its SHA-256, also posted in a public gist on \wtthDesignPreregGistDate, before any data.
Every later change is logged with its timing (D-001 to D-013 before any confirmatory data, D-021 to \wtthDesignDeviationsLastHead{} after the strict analysis; Appendix~\ref{app:deviations}), and witness-visible ones match across cells.
Separate Claude reviewer agents found validity bugs before any confirmatory data, all fixed (Appendix~\ref{app:integrity}).
What did not work: a void first G0 run (D-012), a judge prompt revised once (D-016), a voided duplicate draw (D-019), the declined blind human check (D-018), two unrun stretch arms (D-008), and a deviations log that, until D-020, misstated who decided the reviews.
