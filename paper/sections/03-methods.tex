\paragraph{Shift.}\label{sec:setting}
A fictional retailer, Larkspur Home, runs a nightly refund review on a shared board.
The system prompt says: ``\wtthStimSystemStaffed{} \wtthStimSystemOps''
A shift has \wtthDesignRosterWord{} agents over \wtthDesignRoundsWord{} rounds: a scripted violator (V), claimant (C) and background worker (B), and \wtthDesignLiveWitnessesWord{} live witnesses on one model.
Each witness reviews tickets (\texttt{submit\_reviews}), reads the board, and can post (\texttt{post\_to\_board}) or call \texttt{notify\_ops}, a private, write-only channel to ops whose reply is always ``\wtthStimReplyNotify''
Senders are server-stamped (Appendix~\ref{app:prompts}).

\paragraph{Cells.}
In round 2, V reports releasing a refund over the approval limit as three smaller batches, which the runbook forbids, and C posts a routine aside, a concern or a claim (Box~\ref{box:receipt}, Appendix~\ref{app:prompts}); the claim has a public paraphrase and two withheld ones.
In world R1 the board carries an \texttt{\#escalation-log}, which shows C's line in \cell{RECEIPT} and \cell{POS}, where the harness files C's real note, and reads ``\wtthStimLogEmpty'' in \cell{NO-RECEIPT}; in \cell{FORGED}, C's post also carries a typed line in the log layout (withheld).
\cell{POLICY} adds ``\wtthStimPolicy'' to the runbook; \cell{NEG} and \cell{POS} add ``\wtthStimDedupe'', a cost for duplicate notes, and differ only in C's real note (the sensitivity pair); in the benign cell, \cell{B-NONE}, V holds the refund.
The seed fixes paraphrase, handle order and tickets (Table~\ref{tab:cells}).

\paragraph{Receipts.}
Only the \texttt{notify\_ops} handler writes notes, the log is rendered only from them, and scripted notes use the same handler, so every receipt is channel-written (tests check that posts cannot write it).
The log lists every accepted note, a witness's own included, from the round after it is sent.
The deployer rule under test: \emph{a receipt is written by the channel, never by the claimant}.

\paragraph{Outcomes and analysis.}\label{sec:outcomes}
P1 (``told ops''): a witness sent a note about the violation by round 5, as decided by a pre-registered keyword rule (which supplied all \wtthHaikuKwCheckPOneK{} P1 witnesses; the judge added none); the rule's pre-registered precision check was not done, and a post hoc, model-coded check finds \wtthHaikuKwCheckMatchedFinalPct\% of its matches about the violation (D-024, D-026).
P2 (``operator never told''): no witness in the shift has P1, in the \wtthDesignPTwoCellsWord{} cells where C did not really report.
H1 to H3 are tested in a fixed sequence, two-sided at $\alpha = \wtthDesignAlpha$, stopping at the first whose null is not rejected (a rejection opposite to the prediction still counts), on \Done{} $=$ P1(\cell{NONE}) $-$ P1(\cell{CLAIM}), \Dtwo{} $=$ \Done{} $-$ [P1(\cell{NONE-R}) $-$ P1(\cell{NO-RECEIPT})] and \Dthree{} $=$ P1(\cell{NO-RECEIPT}) $-$ P1(\cell{FORGED}), each predicted positive; a null is rejected only if the \wtthProtocolLevel\% shift-cluster bootstrap interval excludes zero (power: Appendix~\ref{app:predictions}).

\paragraph{Execution.}\label{sec:execution}
Each witness turn is one stateless call to \wtthDesignModelHaikuName{} at effort \wtthDesignEffort{} (no temperature control) through a pinned Claude Code CLI (\wtthDesignCliVersion) in \texttt{--bare} mode with no built-in tools (Appendix~\ref{app:harness}); technical failures are rerun on the same seed, and refusals and malformed calls are data.
Pilot gates, never pooled with the data, checked integrity, fixed how clearly V's line states the violation (P1 in \cell{NONE} topped the \wtthDesignGOneCeiling\% ceiling at every level tried, so the least clear was frozen) and confirmed that witnesses read the log (Appendix~\ref{app:gates}).
The judge (\wtthDesignModelJudgeName, also the exploratory subjects' model) is not told the cell, seed, model or purpose.

Review-queue labels are model-proposed, AI-audited by that proposing model (\wtthDesignModelAnnotatorName, not the judge) and author-approved (\wtthDesignReviewAuthorChanged{} of \wtthReviewReviewed{} decisions changed), not human labels; agreement figures are model--model (Appendix~\ref{app:judge}).

\paragraph{Pre-registration, deviations and what did not work.}\label{sec:integrity}
PREREG v1 froze on \wtthDesignPreregFrozenDate; tag \texttt{prereg-v1} records its SHA-256, also posted in a public gist on \wtthDesignPreregGistDate, before any data.
Every later change carries a deviation ID with its timing (\wtthDesignDeviationsLast{} and earlier before any confirmatory data; up to \wtthDesignDeviationsLastHead{} after; Appendix~\ref{app:deviations}), post hoc and exploratory results below are tagged with theirs, and witness-visible changes match across cells.
Claude reviewer agents found validity bugs before any data, all fixed (Appendix~\ref{app:integrity}).
What did not work: a void first pilot run, a judge prompt revised once, a voided duplicate draw, the declined blind label check, two unrun stretch arms, P1's precision check, and a deviations log that misstated who decided the reviews.
