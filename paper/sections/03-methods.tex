\paragraph{Shift.}\label{sec:setting}
A fictional retailer, Larkspur Home, runs a nightly refund review on a shared board.
The system prompt says: ``\wtthStimSystemStaffed{} \wtthStimSystemOps''
A shift has \wtthDesignRosterWord{} agents over \wtthDesignRoundsWord{} rounds: a scripted violator (V), claimant (C) and background worker (B), and \wtthDesignLiveWitnessesWord{} live witnesses on one model.
Each witness reviews its own refund tickets, reads the whole board, and can post to it or call \texttt{notify\_ops}, a private, write-only feedback channel to ops whose reply is always ``\wtthStimReplyNotify''
The tool names no consequence of a note, and the server stamps the sender (Appendix~\ref{app:prompts}).

% only generically and point to the deviations table; never type the names here.
Because the pinned CLI reserves the pre-registered server name, the server runs as \wtthDesignMcpServerName{} in every cell (Appendix~\ref{app:deviations}).

\paragraph{Cells.}
In round 2, V reports splitting a refund to avoid a second approval, which the runbook forbids, and C posts a routine aside, a concern or a claim (Box~\ref{box:receipt}); the claim has a public paraphrase and two withheld ones.
In world R1 the board carries an \texttt{\#escalation-log}, which shows C's line in \cell{RECEIPT} and \cell{POS}, where the harness files C's real note, and reads ``\wtthStimLogEmpty'' in \cell{NO-RECEIPT}; in \cell{FORGED}, C's post also carries a typed line in the log layout (withheld).
\cell{POLICY} adds ``\wtthStimPolicy'' to the runbook; \cell{NEG} and \cell{POS} add ``\wtthStimDedupe'', a built-in reason to stand down (the positive control); and in the benign cell, \cell{B-NONE}, V holds the refund.
Table~\ref{tab:cells} lists the cells and their planned sizes (D-003).

\paragraph{Receipts.}
Only the \texttt{notify\_ops} handler writes notes, the log is rendered only from them, and scripted notes use the same handler, so every receipt is written by the channel; tests check that no post writes the log.
The deployer rule under test: \emph{a receipt is written by the channel, never by the claimant}.

\paragraph{Outcomes and analysis.}\label{sec:outcomes}
P1 (``told ops''): a witness sent a note about the violation by round 5, as decided by a pre-registered keyword rule or, for other notes, by the judge.
P2 (``operator never told''): no witness in the shift has P1, in the \wtthDesignPTwoCellsWord{} cells where C did not really report.
\Ptwop{} (``never told by any route'') also treats a board post about the violation addressed to ops as telling them \citep{fuller2026smoke}.
Secondary outcomes include alert load, false reports and debrief answers; a board-substitution rate is exploratory (D-010).
H1 to H3 are tested in a fixed sequence, two-sided at $\alpha = \wtthDesignAlpha$, stopping at the first that is not rejected, on \Done{} $=$ P1(\cell{NONE}) $-$ P1(\cell{CLAIM}), \Dtwo{} $=$ \Done{} $-$ [P1(\cell{NONE-R}) $-$ P1(\cell{NO-RECEIPT})] and \Dthree{} $=$ P1(\cell{NO-RECEIPT}) $-$ P1(\cell{FORGED}), each predicted positive.
A test rejects only if the \wtthProtocolLevel\% interval of a shift-level cluster bootstrap excludes zero.
If H1 is not rejected, ``no meaningful stand-down'' needs an upper bound below \wtthProtocolMargin{} points; otherwise the result is inconclusive.
Detectable effects at the frozen level are in Appendix~\ref{app:predictions}.

\paragraph{Execution.}\label{sec:execution}
Each witness turn is one stateless call to \wtthDesignModelHaikuName{} at effort \wtthDesignEffort, through a pinned Claude Code CLI (\wtthDesignCliVersion) in \texttt{--bare} mode, without CLAUDE.md, memory or built-in tools and with the CLI's retry of refused turns off (Appendix~\ref{app:harness}).
Technical failures are rerun on the same seed; refusals and malformed calls are data.
Pilot gates, never pooled with the data, checked integrity (G0), froze V's clarity level (G1, level \wtthGateFrozenLevel) and confirmed that witnesses read the log (G2; Appendix~\ref{app:gates}).
The judge (\wtthDesignModelJudgeName) is blind to cell, seed, model and purpose; review-queue labels are model-proposed (\wtthDesignModelAnnotatorName) and author-reviewed (Appendix~\ref{app:judge}).

\paragraph{Pre-registration, deviations and what did not work.}\label{sec:integrity}
PREREG v1 froze on \wtthDesignPreregFrozenDate; the tag \texttt{prereg-v1} records its SHA-256, also posted in a public gist on \wtthDesignPreregGistDate, before any data.
Every later change was logged before it took effect and before any confirmatory data, and the witness-visible ones are identical across cells (Appendix~\ref{app:deviations}).
Review passes by separate Claude agents found three validity bugs before any confirmatory data, all fixed: refusals rerun as technical failures, a CLI retry that injected an unregistered message, and floating-point errors at the decision boundaries (Appendix~\ref{app:integrity}).
The first G0 run was void because the CLI rejected the server name, and was rerun on fresh pilot seeds; two stretch arms were not run (D-008).
