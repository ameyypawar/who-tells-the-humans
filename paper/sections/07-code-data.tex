\section*{Code and Data}\label{sec:code}
\addcontentsline{toc}{section}{Code and Data}
Repository: \url{https://github.com/ameyypawar/who-tells-the-humans}, public from submission; code under the MIT licence, data under \CCBY.
It holds the pre-registration (tag \texttt{prereg-v1}), the deviations log, the harness and configuration (tag \texttt{frozen-v1}), the judge, annotation and analysis code, and this paper's sources; \texttt{wtth.analysis} regenerates every result and figure from the run database (snapshot \texttt{\wtthSnapshotShaShort}).
Released data: masked transcripts, per-shift and per-witness outcomes, judge and reviewed labels.
Withheld: the two claim paraphrases and the forged line (SHA-256 in Appendix~\ref{app:withheld}), on request to vetted researchers, and the raw API bodies containing them, never released; a rerun needs an Anthropic API key, the pinned CLI (Appendix~\ref{app:harness}) and the withheld file.
\textbf{Preexisting work} predates the sprint start, \wtthDesignTZero{} (Appendix~\ref{app:preexisting}); all harness and analysis code came after it.
