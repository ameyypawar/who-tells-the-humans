\section*{Code and Data}\label{sec:code}
\addcontentsline{toc}{section}{Code and Data}
Repository: \url{https://github.com/ameyypawar/who-tells-the-humans}, public from submission; code under MIT, data under \CCBY.
It holds the pre-registration (tag \texttt{prereg-v1}), deviations log, harness (tags \texttt{frozen-v1}, \texttt{frozen-v1.1}, \texttt{exp1-v1} and \texttt{exp2-v1}), code and paper sources; \texttt{wtth.analysis} regenerates every result from the run database (snapshot \texttt{\wtthSnapshotShaShort}); that database, which holds the withheld strings and raw API bodies, is not released, and \texttt{scripts/}\allowbreak\texttt{release\_summary.py} recomputes the headline numbers from the released CSVs.
Released, for every analysed shift, both follow-ups included (D-029): masked transcripts, per-shift and per-witness outcomes, judge and reviewed labels.
\texttt{kit/o2-receipts/} is a standalone kit for channel-written, checkable receipts on OpenObserve, and \texttt{scripts/}\allowbreak\texttt{openobserve/} holds the post-hoc monitor (Appendix~\ref{app:openobserve}).
Withheld: the two claim paraphrases and the forged line (SHA-256: Appendix~\ref{app:withheld}), for vetted researchers on request; raw API bodies, never.
\textbf{Preexisting work} predates the sprint start, \wtthDesignTZero{} (Appendix~\ref{app:preexisting}); all study code came after it.
