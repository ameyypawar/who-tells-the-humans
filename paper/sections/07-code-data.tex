\section*{Code and Data}\label{sec:code}
\addcontentsline{toc}{section}{Code and Data}
Repository: \url{https://github.com/ameyypawar/who-tells-the-humans} [A: public at submission; licences for code and data].
It holds the pre-registration (git tag \texttt{prereg-v1}; SHA-256 of PREREG.md \texttt{\wtthDesignPreregShaShort}\ldots) with the witness-visible prompts frozen by the same tag; the deviations log (D-001 to \wtthDesignDeviationsLast); the harness (\texttt{src/wtth}); the configuration frozen at tag \texttt{frozen-v1}; the judge and analysis code; and the sources of this paper.
Every result number and figure is regenerated from the run database by \texttt{wtth.analysis} (snapshot \texttt{\wtthSnapshotShaShort}).
Released data [A: confirm]: per-shift and per-witness outcome tables, judge labels and reviewed labels, and transcripts with the withheld strings masked.
Withheld: the two claim paraphrases and the forged receipt-style line, pre-registered by SHA-256 (Appendix~\ref{app:withheld}), and the raw API request bodies, which contain them.
