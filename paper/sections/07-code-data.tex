\addcontentsline{toc}{section}{Code and Data}
Repository: \url{https://github.com/ameyypawar/who-tells-the-humans}, public from submission; code under MIT, data under \CCBY.
It holds the pre-registration (tag \texttt{prereg-v1}), deviations log, harness (tags \texttt{frozen-v1}; \texttt{frozen-v1.1} after the D-014 fix; \texttt{exp1-v1}, follow-up), code and paper sources; \texttt{wtth.analysis} regenerates every result (snapshot \texttt{\wtthSnapshotShaShort}).
Released, for every analysed shift: masked transcripts, per-shift and per-witness outcomes, judge and reviewed labels.
Withheld: the two claim paraphrases and the forged line (SHA-256: Appendix~\ref{app:withheld}), for vetted researchers on request; raw API bodies, never.
\textbf{Preexisting work} predates the sprint start, \wtthDesignTZero{} (Appendix~\ref{app:preexisting}); all study code came after it.
