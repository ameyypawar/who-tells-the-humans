\subsection{Integrity: bugs caught before data}\label{app:integrity}
Before any confirmatory data, separate Claude agents, each in a fresh context, reviewed the design and the code: design reviews before the build, a second code review of the harness, and a review of the judging and analysis code.
These were model reviews, not human code review.
They found these validity bugs, all fixed before any confirmatory data.
\begin{enumerate}
\item \textbf{Refusals rerun.} The pinned CLI reports a refusal as a successful result with an error flag and a refusal stop reason, a shape the test client never produced. Real refusals would have been classified as technical failures and rerun, which resamples on the outcome. They are now data and never rerun (D-009).
\item \textbf{An injected message.} The CLI retries a refused turn once by itself and shows the model a message saying that its previous response was stopped by a safety classifier. That text is not part of the pre-registered stimulus, and the retry hides the refusal. The retry is disabled in every turn (D-009).
\item \textbf{False stops from model text.} Clipped turns had their model text scanned for API-error words, and refund-desk words such as ``payment'' would have caused false stops and reruns. Clips are now classified from the result record alone (D-009).
\item \textbf{Floating-point verdicts.} Rates are ratios of integers, and floating-point subtraction left mathematically zero difference-in-differences slightly above or below zero. This could have rejected H2's null at an interval endpoint of exactly zero, and it licensed the null claim at an upper bound of exactly \wtthProtocolMargin{} points, which the pre-registration forbids. The decision layer now uses exact arithmetic.
\item \textbf{Wrapped replies.} The tool framework wrapped every reply in JSON instead of the pre-registered bytes. The server now returns the bare reply, and G0 checks the bytes the model sees (D-005).
\end{enumerate}
Two later problems were found and fixed after collection and before any review report: the false positive in the raw-body check (D-014) and the duplicate draw of the review sample (D-019).
A third was in the record, not the data: the paper review found that the deviations log did not say who made the review decisions, which D-020 now records.

Two checks need a word.
The receipts gap was nominally inside its margin (\cell{NONE-R} $-$ \cell{NO-RECEIPT}: \wtthHaikuHTwoDeltaROne{} points, CI \wtthHaikuHTwoDeltaROneCI, an interval that crosses the margin), but with the log the claim's stand-down grew rather than shrank (H2 opposite to prediction), so the receipts prediction is not supported.
\cell{POLICY} sat between \cell{CLAIM} and \cell{NONE} only nominally: \cell{POLICY} $-$ \cell{CLAIM} was \wtthHaikuPostHocPredPolicyMinusClaimDelta{} points (CI \wtthHaikuPostHocPredPolicyMinusClaimCI) and \cell{NONE} $-$ \cell{POLICY} \wtthHaikuPostHocPredNoneMinusPolicyDelta{} (CI \wtthHaikuPostHocPredNoneMinusPolicyCI), within noise.
The power figures use the planning base rate of \wtthHaikuPowerP\%, not the realised ceiling, so they do not describe the realised precision: the effects detectable at \wtthDesignPowerPct\% power are \wtthHaikuPowerHOneMDE, \wtthHaikuPowerHTwoMDE{} and \wtthHaikuPowerHThreeMDE{} points for H1 to H3 (assumed intra-class correlation \wtthHaikuPowerRho), and under a true stand-down of zero the H1 null rule would be met with probability \wtthHaikuPowerHOnePNullDZero\%.
The realised intervals (Table~\ref{tab:hyp}) are far narrower, because binomial variance is small near the ceiling; this, not the design, is why H1 rejected an effect an order of magnitude below its planned detectable size.
