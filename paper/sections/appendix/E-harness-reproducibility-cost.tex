\section{Harness card, reproducibility and cost}\label{app:harness}

\subsection{CLI and flags}
The pinned Claude Code CLI is version \wtthDesignCliVersion, a copy kept outside the auto-updater's folder (\mbox{D-002}), with SHA-256 {\footnotesize\texttt{\wtthDesignBinarySha}}.
Its version is asserted on every call.
Each witness turn is one call with the flags below; debrief turns use the same call without the MCP flags and with a step cap of two.

The orchestrator passes the MCP server its identity (shift, attempt, round, slot, sender handle, shift clock, world) through the server's environment for that turn only; no tool argument can set it.
The server refuses to start if an environment variable name looks like a credential (D-009).

\subsection{Environment}
The turn environment is built from scratch and never inherits the parent process's.
The API key goes only into the experiment's own subprocesses (D-001).
\texttt{CLAUDE\_CODE\_DISABLE\_REFUSAL\_RETRY} is present in the pinned \wtthDesignCliVersion{} binary but undocumented (the public docs list a refusal-fallback variable instead), so its effect rests on our own checks: with \texttt{switchModelsOnFlag} false set through \texttt{--settings}, every turn's \texttt{modelUsage} was checked, and of \wtthTurnIntegrityOkN{} ok turns (every phase of the main database: gates, pilots, core, Sonnet arm and follow-up) \wtthTurnIntegrityOkOtherModelK{} were answered by a model other than the one requested, with \wtthTurnIntegrityRefusalStopK{} refusal stops and \wtthTurnIntegritySafetyStopK{} safety stops.

\subsection{Init and result assertions}
Each turn's stream must report the pinned CLI version, the requested model, API-key authentication, the fixed working directory, exactly our three tools under one connected MCP server, and no skills or slash commands; debrief turns must report no tools and no MCP server.
The result must name only the requested model, with a first-party provider and list-price cost basis, and no permission denials.
Every tool reply must equal its pre-registered bytes.
Any mismatch makes the turn a technical failure.
The init also lists the CLI's three built-in plugins (agents-md, privacy, plugin-authoring), against the pre-registration's ``no plugins'' (D-026); the raw-body audit shows they add no system text, tools, skills or commands on audited turns, which are every G0 turn and a sample of production turns.

\subsection{What the model sees}
Under \texttt{--bare} with an API key, the system context is a billing header, the SDK's identity line, our system prompt and our tools; it is the same in every cell.
The raw-body audit checks this on every G0 turn and on a deterministic sample of production turns (one in \wtthDesignAuditSampleMod{} by turn id); it also checks that request bodies contain no user name, e-mail address, CLAUDE.md or memory text, and a failed audit stops the run (D-005, D-009).

\subsection{Failure taxonomy and counts}
\textbf{Technical}, rerun as a new attempt on the same seed, at most \wtthDesignMaxAttemptsWord{} attempts per shift: rate-limit, server and transport errors, MCP crashes, failed init assertions, server or database faults, process kills and the \wtthDesignTurnTimeout-second turn timeout.
A debrief call that fails technically is retried in place with identical inputs.
\textbf{Data}, kept and counted by cell: refusals, empty turns, turns with no tool call, off-task text, test suspicion, tool-argument validation errors, step-cap clips and budget clips.
\textbf{Stop for a human decision}: integrity failures (exposure, which also checks that the rendered log equals the channel's log rows, and reply bytes), billing errors, repeated breaker trips and unexplained error results; that only the channel writes receipts holds by construction and is checked by tests (Section~\ref{sec:methods}).
Counts by cell follow.
\texttt{turns\_refusal} counts turns that ended with a refusal stop reason, and there were none; \texttt{turns\_refusal\_text} counts turns whose text matched the pinned refusal phrase rule, which are candidates only, kept as ordinary data, and no read of them is reported here.

\subsection{Analysis set}
The confirmatory set is every seed up to $s_c$, the largest seed such that every planned (cell, seed) at or below it is done or permanently failed (D-008); here $s_c$ is \wtthHaikuSC.
Shifts above $s_c$ (\wtthHaikuEpisodesAbove) and shifts completed but not planned are reported separately and are exploratory (D-011).

\subsection{Reproduction}
The repository README gives the commands; the main ones are:
\begin{itemize}\raggedright
\item \texttt{wtth manifest --phase core --verify}: start-up checks;
\item \texttt{wtth run --phase <phase> --live}: one phase (the gates, \texttt{core}, \texttt{sonnet});
\item \texttt{wtth render --cell <cell> --seed <seed> --round <round> --slot <slot>}: print a prompt (withheld seeds need an explicit flag);
\item \texttt{wtth audit}, \texttt{wtth gate} and \texttt{wtth status}: gate checks and progress;
\item \texttt{python -I -m wtth.judge} with \texttt{extract}, \texttt{validate} and \texttt{run --tier <tier>}: the judge;
\item \texttt{python -I -m wtth.annotate} with \texttt{queues}, \texttt{export}, \texttt{import-labels}, \texttt{report} and \texttt{import-review}: the review queues;
\item \texttt{python -I -m wtth.analysis run --strict}, with \texttt{--export-paper <dir>}: every number, table and figure of this paper.
\end{itemize}
Runs resume from the database after any interruption, and finished shifts are never touched.
A rerun needs an Anthropic API key, the pinned CLI and the withheld file (Appendix~\ref{app:withheld}).

\subsection{Software}
Python \texttt{3.12.13}, the MCP Python SDK \texttt{1.30.0} (pinned below the major version that renamed its server class), and numpy, scipy, pandas, statsmodels and matplotlib at the versions in \texttt{requirements.txt} and \texttt{requirements.lock} (pandas is an indirect dependency, through statsmodels); this paper builds with tectonic.

\subsection{Cost}
All experiment agent calls, judge calls included, go to one API credit (D-001) under one ledger with a hard cap of \wtthDesignCapUsd, of which \wtthDesignJudgeReserveUsd{} was reserved for judging (D-005, D-009).
A shift launches only if spend plus the worst case of calls in flight fits under the cap.
After collection, and before any judge label existed, the cap was raised once so that the judge could use the rest of the credit (D-015).
The annotation subagents ran on the author's subscription, outside the cap (D-011).
Experiment calls cost \wtthCostMainUsd{} and judge calls \wtthCostJudgeUsd, \wtthCostTotalUsd{} in all so far, the exploratory follow-up of D-022 included (its budget rules: D-023); the Haiku core ran in \wtthOpsCoreWallHours{} hours, from \wtthOpsCoreStart{} to \wtthOpsCoreEnd.
