\section*{LLM Usage Statement}
\addcontentsline{toc}{section}{LLM Usage Statement}
The author designed and directed this study and made or approved every decision recorded in the pre-registration and the deviations log.
Claude models (Anthropic) were used through Claude Code, as follows.

\paragraph{(a) Research and design support.}
Claude agents compiled the pre-sprint notes on the literature and prior art, and the framework audit; a Claude agent re-checked every audit row against its primary sources and applied the explicit rubric (Appendix~\ref{app:audit}).
Claude drafted the pre-registration and the witness-visible prompts; the author edited and approved them.
The stimuli are therefore Claude-written text shown to a Claude subject (Appendix~\ref{app:limits}).

\paragraph{(b) Code.}
Claude wrote most of the harness, the judge pipeline and the analysis code.
Before any confirmatory data, separate Claude agents, each in a fresh context, reviewed the code and the design.
These were model reviews, not human code review; the bugs they found are listed in Appendix~\ref{app:integrity}.

\paragraph{(c) Running the study.}
Claude agents launched and monitored the gates, the runs, the judge and the annotation pipeline under a gate playbook that the author had pre-authorised.
Anything outside the playbook stopped the run for the author's decision.

\paragraph{(d) Measurement.}
\wtthDesignModelHaikuName{} and \wtthDesignModelSonnetName{} are the subjects, and \wtthDesignModelJudgeName{} is the LLM judge.
Fresh \wtthDesignModelAnnotatorName{} subagents proposed a label, with a one-line rationale, for each item in the review queues without seeing the judge's labels.
At the author's request, a second \wtthDesignModelAnnotatorName{} pass in a fresh context, given the review instructions and the label definitions, read all \wtthReviewReviewed{} review blocks and pre-filled a decision for each: approve the proposal, correct it, or take the judge's label (D-020); it ran on the proposer's model, so it is not independent of the proposals.
The author read the pre-filled file and approved it as it stood, changing none of the \wtthReviewReviewed{} decisions; his correction rate is \wtthDesignReviewAuthorChanged{} of \wtthReviewReviewed.
We therefore report model-proposed, AI-audited, author-approved labels.
They are not blind or independent human labels.
No blind human reliability check was done (the planned blind sample was declined, D-018), so there is no human--judge $\kappa$, and every agreement figure in this paper is model--model.
